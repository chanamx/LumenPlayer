# Lumen Player 1.6.0 交互与播放列表验收

日期：2026-10-19。当前安装程序为 `dist/LumenPlayer.exe`，与通过隔离发布验收的程序散列一致。

## 完成的行为

1. 设置中的解码开关立即切换当前视频，在准备好替代管线后释放旧管线，保留时间、音量及播放/暂停意图，停止并重连字幕采集。请求不支持时保留正在使用的管线。开关关闭为软件解码，开启为 Windows 硬解优先路径；“硬优先”不声称已观测到 GPU 解码。
2. 设置内开关实时字幕不选择播放状态。模型在后台加载，完成、关闭和加载期间反复开关均保留用户选择。字幕已开启时打开媒体的原有起点等待策略保留。
3. 倍速绑定键盘 →，点按前进 5 秒，长按约 0.34 秒进入设置中的倍率，松开或失焦恢复。鼠标右键不再触发倍速；不支持原生倍速的解码器保留跳帧快进回退。
4. 进度条不再绘制悬停/焦点圆角外框，焦点由滑块显示。播放按钮处理双击序列中的第二次按下；系统和软件路径各 32 次快速点击均逐次改变播放意图。提示气泡避开字幕与列表操作区域。
5. 播放列表支持主列表、命名列表文件夹、新建/重命名/删除、多文件添加、非递归目录导入、自然排序及去重。新增 ⏮ / ⏭ 专用于文件切换，宽窗口保留 ±10 秒定位。支持 P、PageUp/PageDown、列表选择/回车/Delete、滚轮和拖动滚动条。
6. 浏览的列表文件夹与播放队列分开：切换浏览不打断当前播放；选中媒体播放后才换队列。缺失路径跳过，末项停止，移除条目不删除磁盘文件。删除正在播放的条目保留媒体播放并解除该列表的续播关联。
7. 列表用一个 UTF-8 元数据文件原子保存，限制 128 个列表文件夹、总计 10,000 个条目和 8 MiB 文件；损坏或不支持的文件保留且禁止自动覆盖。关闭及重启后恢复上次列表文件夹，否则回到主列表。
8. 未保存的实时字幕与音频块仅保存在内存，退出时停止线程、释放模型并清空会话。导出 SRT 仅由用户保存操作触发。正式程序实际生成 2 条未保存字幕后正常退出，程序和媒体目录内字幕/临时导出文件的快照未变化；已导出字幕在原生回归中被确认保留。
