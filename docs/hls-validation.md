# Lumen Player 1.7.0 M3U8 与 HLS 验收

日期：2026-10-20（10 月 19 日开始实施）。安装程序与本次正式验收程序 SHA-256 一致。

## 使用和实现

- Ctrl+U 或打开菜单输入 HTTP/HTTPS 视频、直播和 M3U/M3U8 地址。文件选择、拖入文件和命令行可导入本地清单。列表“添加媒体”菜单支持文件和地址，并保留当前播放状态。
- 每份清单单独建立列表文件夹，保留 UTF-8 `#EXTINF` 名称、清单来源、相对路径和精确网络地址。再次导入同一来源合并现有条目、更新名称。导入频道清单时每项作为节目；HLS 主清单/分片清单作为一个完整节目，不将分片和码率拆成条目。
- 一个后台任务准备源，取消后先完成旧任务回收，再处理排队的新任务。读取有超时和取消；准备失败保留当前媒体。原视频继续播放时可以准备新源。关闭前中断网络读取，避免线程等待卡住退出。
- HTTP(S) 的网络协议白名单不允许转读本地文件。HTTPS 启用证书校验。普通本地容器维持禁止外部 I/O 的处理；用户选择的本地 HLS 允许读取相对分片/密钥及 HTTP(S) 分片。
- 本地清单的 Unicode、空格、#、% 路径经过实际解码。HLS URI 相对解析转义特殊符号，仅在本地文件 I/O 中还原，不改写网络查询参数。
- 点播支持异步定位。直播保持未知总时长，显示已播放时间；禁用定位和临时倍速，进度条不绘制虚假完成百分比。
- 网络/HLS 字幕采集直接使用实际输出的 PCM，不创建第二条媒体连接。暂停不喂入，定位清空旧时间上下文，播放结束/关闭补齐末句。用户未保存的字幕保持在内存。
- 列表格式 2 保存来源和名称，继续读取格式 1；安装时保留现有数据，首次编辑保存时写新格式。数据大小/条目/列表上限和原子替换保持有效。

## 验证

完整原有回归 **1530 项**通过，HLS 专项 **60 项**通过。日志：`regression.log`、`network-regression.log`。

专项使用标准库临时 HTTP 服务，包含动态直播清单、重定向、查询参数、404、卡住的连接及禁止的本地引用。9 个播放输入覆盖本地 TS、主清单、fMP4、AES128、中文/空格/#/% 路径，以及 HTTP 的 fMP4、AES128、主清单和带查询参数 TS。均读取真实音视频并推动播放时钟。

验证 URI/名称保存恢复、同源重复导入、非法格式拒绝、真实文件夹导入、后台失败不打断旧媒体、暂停停止字幕音频、点播定位后的字幕时间、直播无虚假进度。实际 Zipformer 模型从直播输出生成中文字幕，并可主动导出 SRT。连接取消采样 **99.48 ms**，仅代表本机回环服务这次采样。

正式程序在隔离目录通过两次独立进程启动，首次从 `.m3u8` 导入并播放、保存独立文件夹和节目名称，第二次恢复后用列表激活；验证上下项切换、跳过缺失条目和媒体文件不变。列表调宽、重启恢复、按钮/双击重置及 Escape 恢复视频宽度保持通过。本机正式窗口缩放为 125%。

正式 H.264、HEVC、特殊安装路径 WebM/Opus、中文语音、HLS 点播和动态直播均通过模型/采集就绪、窗口响应、正常退出和验收数据恢复。正式直播退出时丢弃 **2 条**实际生成而未保存的字幕，字幕/临时文件快照未变化。相关证据 `hls-release-*.json`。

公网 HTTPS 使用 [Apple 官方 HLS 示例](https://developer.apple.com/streaming/examples/advanced-stream-hevc.html)中的子清单，验证证书校验和实际画面解码：`https://devstreaming-cdn.apple.com/videos/streaming/examples/bipbop_adv_example_hevc/v1/prog_index.m3u8`。记录 `hls-https-probe.json`。多路高级主清单的首轮测试触及 20 秒准备期限，保留失败日志，不将子清单的成功推广为所有复杂清单的保证。

原有媒体矩阵 68 项：66 个有效输入成功、2 个损坏输入安全拒绝；216 次进度拖动、64 次快速播放键点击、解码双向切换、真实字幕重定位和 144 组列表布局继续通过。首轮完整回归曾出现一次原有 Right Arrow 时序断言失败；相同构建专项复验及后续完整回归通过，没有放宽断言。原始记录保留在 `hls-full-initial.log`。

## 交付和范围

EXE 779,776 字节，SHA-256 `f10ebc87776ffebfca195de8a0d80e67fca2448945bf785fbcf1b1d0381de943`。安装记录 `hls-installation.json`，用户 INI 和列表逐字节保留。恢复备份 `build/backups/pre-hls-20261019.zip` 包含 1.6.1 程序、源码、设置及旧散列清单。

复用既有 FFmpeg/ASR 运行库和同一模型/词表，没有新增播放器运行包 DLL；新增 WinHTTP 来自 Windows。清理重复构建/路径测试副本 581.99 MiB，保留依赖原件、正式包、备份和验收证据。当前文件清单 `release-manifest.json`。

当前为 UTF-8 扩展 M3U、HTTP(S) HLS 与现有软件播放管线；不包含 DRM、专用网页登录、流内字幕轨选择或手动多码率菜单。网络/HLS 不提供播放中的系统硬解切换，音频设备变化或源的滚动窗口过期时可能需要重新打开。没有把回环环境性能数字或一次公网连接推广到全部网络。

复验：`powershell -ExecutionPolicy Bypass -File test.ps1`；HLS 专项：构建 Test 后 `python test/run_network_checks.py`；正式直播：`python test/run_network_checks.py --release`；正式导入：`test/smoke-playlists.ps1 -VerifyImport -VerifyDock -ResultName hls-release-smoke.json`。
