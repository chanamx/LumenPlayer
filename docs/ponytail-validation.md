# LumenPlayer 2.0.0 Ponytail 优化验证

本文保留 2026-10-22 的历史优化与当时的验证结果；当前源码和发布程序的深度调优见 [2026-10-23 验证报告](deep-tuning-validation-2026-10-23.md)。历史哈希和测量不作为本轮最终版本的验收证据。

最终优化程序已替换至 `dist/LumenPlayer.exe`，SHA256 `dd14bf1d9987ae00c9f9dab7314d3d15150f3a1c88b6b2acb0456da7422ee2b7`，954,368 字节。对照程序 SHA256 `ee8ee900607bc08a6fb0a0f517f03639b7b82b801831a440b48612d81afe25e2`，959,488 字节。

本次采用 Ponytail 最小改动原则，减少高频重复分配、无用查询、空闲轮询和构建重复副本。现有操作、输出参数、画质、模型和功能范围保持；34 个运行 DLL、模型、设置与播放列表均与本次开始前相同。

## 生产改动

1. 播放状态与音轨、设备、协议列表分开，约 35 ms 的播放状态刷新无需复制三个列表；列表读取频率保持原策略。
2. 固定协议表在核心初始化时读取一次，删除未使用的 `vo-passes` 查询，色调/色域映射白名单改用静态数组。
3. PCM 队列为空时等待通知，取消 20 ms 空轮询。退出标志在同一把队列锁内更新后通知，避免关闭时遗漏唤醒；PTS、暂停、过期音频丢弃及队列上限保持。
4. 原子比较交换保护内部定位事件与用户定位的代际交接，避免检查与递增之间覆盖新到的定位请求。
5. 固定暂存资源更新使用临时文件及目录项替换，真实硬链接夹具确认更新暂存文件不会写坏固定源文件。

生产差异见 `build/ponytail-20261022/production.diff`，修改前源码 ZIP、原始 EXE、运行库与用户数据恢复包均保留。模型保留固定源和开始前 SHA256，恢复包不重复收录模型。

## CPU 与内存实测

同一主机、同一 `tracks-effects.mkv` 和相同运行库，硬件优先、gpu-next、WASAPI，使用独立基准目录。旧/新版交替顺序。三种场景各三对，共 18 个进程；实际输出就绪后预热 750 ms，每约 200 ms 采样，时间约 4 秒。字幕模式确认同连接 PCM、模型启动和播放释放。

CPU 表示“进程 CPU 秒 / 实际采样秒”的每轮值再取中位数；1.0 对应一个逻辑核心，不是整机任务管理器百分比。私有内存是每轮多次采样平均值再取中位数，单位 MiB，属于私有提交量。

| 4 秒短测场景 | 旧版 CPU 秒/秒 | 新版 CPU 秒/秒 | CPU 变化 | 旧版私有内存 MiB | 新版私有内存 MiB |
|---|---:|---:|---:|---:|---:|
| 暂停操作后 | 0.0192 | 0.0424 | +120.8% | 91.10 | 84.86 |
| 普通播放 | 0.0560 | 0.0857 | +53.2% | 90.98 | 89.77 |
| 实时字幕播放 | 0.2177 | 0.2224 | +2.2% | 316.20 | 316.30 |

短测多轮的 CPU 结果方向曾变化，不能用早期约 39% 的降幅代表最终收益。进一步预先固定 **8 秒采样、5 对普通播放，共 10 个进程**，得到：

| 更长普通播放对照 | 旧版 | 新版 |
|---|---:|---:|
| CPU 秒/秒中位数 | 0.06899 | 0.06893 |
| 私有内存 MiB 中位数 | 91.22 | 91.01 |
| 输出就绪 ms 中位数 | 545 | 585 |

较长对照 CPU 差异约 -0.08%，基本持平；私有内存约减少 0.21 MiB，也不足以确认稳定收益。本轮未证实 CPU、启动速度或整体内存的显著改善；代码消除的重复工作与磁盘副本精简是明确的结构性结果，不据此推断固定百分比提速。

全部 28 个进程均确认真实输出、窗口响应及正常退出。短测暂停场景通过原生窗口发送暂停操作，未另外读取后端暂停属性；其内存变化不单独宣传为稳定收益。单机、短视频与有限样本不能代表所有文件和设备，也没有长期内存增长结论。

原始数据：`test/results/ponytail-performance.json` 和 `ponytail-performance-playing-extended.json`。前期结果和失败日志保存在 `build/ponytail-20261022`，不会作为当前最终哈希的成功证据。

## 空间结果

- 37 个固定暂存 DLL/模型文件按 SHA256 比对后使用 NTFS 硬链接，原来仅有一处链接的重复副本减少 **365,703,980 字节，约 348.76 MiB**。dist 仍是独立完整发布副本；相同路径和字节保持。
- EXE 减少 **5,120 字节（5 KiB）**；最终安装包减少 **13,426 字节（约 13.1 KiB）**，当前 186,231,988 字节。
- 新增程序、运行库与用户数据恢复 ZIP 84,767,433 字节，约 80.84 MiB；另保留原始 EXE、约 0.36 MiB 源码 ZIP 和中间修订的程序检查点。348.76 MiB 为副本合并毛收益，恢复和证据文件另占空间。
- 中文/空格/特殊路径副本、基准目录、重新展开的网络测试服务、编译临时目录已清理，捕获逐文件哈希。基准资产大多原为硬链接，其逻辑字节不与实际回收空间重复相加。
