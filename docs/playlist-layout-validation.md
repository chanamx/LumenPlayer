# Lumen Player 1.6.1 播放列表布局验收

日期：2026-10-19。当前安装程序为 `dist/LumenPlayer.exe`，与本次隔离发布验收的程序散列一致。

## 调整后的行为

- 播放列表从共享标题栏下方贯通到窗口底部；全屏时从屏幕顶部到底部。视频子窗口、外挂及实时字幕、音频卡片、提示和底部播放条都按左侧区域布局，播放条右侧与列表边缘对齐。
- 默认宽度由 348 缩为 **320 个逻辑像素**，支持拖动左边缘调宽。释放鼠标或丢失捕获时保存宽度，重启后恢复。拖动过程中仅更新布局与原有视频窗口，不重开媒体或加载字幕模型。
- 列表标题右侧“重置”、双击分隔边缘可恢复 320。Tab 选中边缘后，←/→ 每次调整 8 个逻辑像素，Home/回车重置，不会定位视频或启动临时倍速。
- 正常窗口下列表最窄 240、左侧至少保留 320 个逻辑像素；窗口缩小时仅限制实际宽度，不覆盖用户偏好。放大后恢复首选宽度。在窄窗口中重置也保存 320，而不会错误地把临时显示宽度当成默认值。
- 窄播放区将时间移到进度条上方，并通过“…”菜单提供字幕、音量及设置操作。布局检查包含进度条实际点击范围，避免它覆盖按钮上缘。小窗口欢迎页使用紧凑排列，打开按钮清晰可点。
- 单击画面、操作播放条、切换文件时保留列表展开。列表底部与分隔边缘不作为播放/暂停目标。鼠标按下同步位置，取消手势时统一释放自己的捕获，避免前一轮捕获干扰下一次调宽。

## 原生与正式程序验证

完整原生回归 **1530 项断言通过**，包含本轮布局、真实播放、连续进度拖动、实时字幕、字幕清理及此前交互功能。日志 `test/results/regression.log`。

布局矩阵共 **144 组**：560/640/760/820/1120/1440 逻辑像素的客户区宽度，240/320/480/900 首选列表宽度，100%/150%/200% DPI，普通窗口及全屏。逐组检查贯通高度、共同边界、最小可用区、宽度偏好不被覆盖、播放控件及点击范围互不覆盖、重置及欢迎页可用。

实际软件与硬件优先两条播放管线，各在播放和暂停状态下往返调宽；检查文件与管线不变、播放意图不变、时间不跳转、音频采集持续。通过 GetClientRect/坐标映射检查两种视频子窗口均与左侧区域一致。验证捕获丢失提交宽度、键盘调宽、两种重置、窄窗恢复、隐藏列表和 Escape 即时恢复视频宽度、全屏边界，以及画面点击不收起列表。

正式 1.6.1 程序在隔离目录经过两次独立启动，以真实窗口消息在本机 125% 显示缩放下验证以下过程：默认 320 → 拖动至 376 → 关闭并重启恢复 376 → 标题按钮重置 320 → 拖动至 360 → 双击边缘重置 320 → Escape 恢复完整视频窗口。同步检查硬件/软件子窗口，保留已有的列表文件夹恢复、上下项切换及缺失文件跳过验证。证据 `test/results/layout-release-smoke.json`。

正式程序的 H.264、HEVC、中文/空格/#/% 安装路径 WebM/Opus、中文语音字幕清理，均完成模型/音频采集就绪、窗口响应和正常退出验收。实际生成 **2 条未保存字幕**后退出，字幕/临时导出文件快照未变化。验收自身 INI 与列表文件逐字节恢复。证据 `layout-release-h264.json`、`layout-release-hevc.json`、`layout-release-path.json`、`layout-release-caption-cleanup.json`。

原有 68 个媒体兼容用例中 66 个有效输入成功解码、2 个损坏输入安全拒绝；216 次独立进度拖动压力用例、两种管线共 64 次快速播放键点击、8 次即时解码切换及真实字幕管线切换保持通过。模型、词表、运行库和播放/识别实现文件与 1.6.0 散列一致。
