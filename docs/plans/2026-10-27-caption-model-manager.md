# Caption Model Manager Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 用户可在实时字幕中选择已验证识别/翻译模型及下载源，自行安装、取消与删除；安装包不包含识别权重，保留既有数据和旧模型。

**Architecture:** 固定版本的模型目录及完整文件校验值编译进应用；单个后台安装任务将数据写入应用 models 下的临时目录，校验完整包后原子发布。原有 PCM 采集继续复用同一播放连接，识别引擎增加 Moonshine；翻译独立工作线程处理最终句，显式选择后启动受限的本地原生翻译进程，过期任务按播放代际丢弃。设置页增加原生模型管理窗口，显示用途、语言、资源档位、来源、下载/安装状态和用户选择。

**Tech Stack:** C++17 / Win32 / Direct2D、WinHTTP、BCrypt SHA-256、Sherpa C API、Moonshine C API、固定版本 llama.cpp Windows CPU 运行库；PowerShell 构建和安装包，项目本地 Python 验证。

## 界面与选择

采用现有设置页中的“模型与语言”按钮，打开原生键盘可访问的深色管理窗口。列表展示模型用途、语言、总体下载大小、安装/下载状态；选择行显示实测档位和作者来源，可选择来源、下载安装、取消、删除及设为识别/翻译模型。翻译目标与识别语言分开。首次没有权重时引导安装，普通播放继续可用。

识别候选先收录现有中文、Moonshine 日语 Tiny、英语 Tiny/Small（Small 一秒更新）、已通过前轮范围内测试的德语 Tiny。翻译收录 Hy-MT2/Index 中配以上选项。CAT 的下载和日英试测在新实验目录继续，只有完整校验、质量/速度验证通过后才纳入可用目录；LFM2.5 小模型等未达质量门槛的候选不纳入。

下载源按模型逐文件固定，不将不同模型或不匹配词表拼成一包。默认自动选源；显式选择来源时如辅助文件需要另一个已验证来源，界面明确说明。只用 HTTPS 和标准证书验证，保留取消后的可恢复临时文件；403/429/503 不持续重试。尚不自动启用任何新下载模型。

## Task 2: Fixed catalog and model store

- 新增 src/caption_models.h/.cpp、生成后的固定目录及资源清单。
- 实现已安装检查、后台安装进度/取消、完整大小和 SHA-256 校验、同卷临时目录发布、受限删除及旧中文模型发现。

## Task 3: Recognition engines

- 修改 src/captions.h/.cpp，保持原调用接口兼容，增加模型选择和 Moonshine 原生流式实现。
- 共用当前有界 PCM 队列和重采样；正确处理首包时间、暂停、跳转、超载、结束、取消和卸载。
- 将固定版本 Moonshine C ABI 与许可/来源随构建验证，复用当前 ORT，不混入其他运行库。

## Task 4: Translation pipeline

- 新增本地原生翻译服务生命周期及翻译队列；仅在用户选择的模型已安装并选择目标语言后启动。
- 固定 CPU/上下文/缓存限制，隐藏子进程并使用所有权明确的作业对象；关闭、失败、换模型及时结束自建进程。
- 识别文本始终保留，翻译结果带原文与媒体时间；不显示过期媒体/跳转代际的结果，不把翻译首 token 当整句完成。

## Task 5: Model manager UI

- 新增 src/model_dialog.h/.cpp；修改 src/main.cpp 的配置、设置布局、模型状态和启停逻辑。

- 使用中的模型先停止并释放后才能删；只删除应用登记的文件，保留未知文件、既有设置和播放列表。
