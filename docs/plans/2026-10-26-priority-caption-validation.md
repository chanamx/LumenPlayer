# 日语、英语与中英/中日优先的补充验证

用户顺序：日、英、中英、中日、基本通用、德、法。中英/中日先按双向翻译测试。保留此前真实代际、质量和本机实时性要求；Index、Hy-MT2 等 1.8–2B 继续作为中配以上可选档。

1. 日语：补充带参考文本的不同自然语音，比较 Moonshine v2 Tiny 与 Small，使用当前 ORT；测试连续语音、静音与受控噪声，不将重复片段算成独立样本。
2. 英语：扩展独立片段和连续输入，检查 Tiny 的稳定性，必要时用已有 Small 做质量参照，记录更新间隔对延迟和资源的影响。
3. 中英、中日：继续筛选真实 2026 新训练的小型专用翻译器；对已有候选增加目标方向的关键语义对照。更大模型保留硬件分档。
4. 测试任务串行执行，缓存和下载限定本实验目录，保留内存提交与超时保护。完整模型与辅助文件校验后才使用。
5. 保存参考、识别输出、翻译输出、时序、CPU、内存和失败记录，写入新报告，不改前轮证据，不切换正式模型或安装包。
