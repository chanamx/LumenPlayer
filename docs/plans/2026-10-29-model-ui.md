# 模型窗口轻量微调

以已发布的 2.2.0 为基线，优先改善模型与语言窗口。使用原生列表、组合框、按钮的绘制与键盘行为；不增加 UI 框架、图片、动画或后台渲染线程。

- 采用播放器已有的深灰与蓝色体系。标题 20 px、正文 14 px、辅助文字 12 px；主要间距 8 / 12 / 20 px。
- 当前识别与翻译分行显示；模型列表增加行高、明确选中状态，详情与下载操作分区。
- 下载安装、启用模型与删除有不同视觉层级；保留禁用、悬停、按下、键盘焦点，以及原生 Tab / 方向键 / Esc。
- 按 DPI 更新字体、行高和布局，小窗口保持操作可达；读取状态后仅更新变化的文字、进度和启用状态。
- 先留存旧窗口原生绘制与性能样本，再用同一原生组件探针对比新窗口。验证实际模型安装、语言切换、启用和释放，运行播放器回归与正式程序 smoke。

不修改模型身份、下载校验、推理、解码或字幕生命周期。测试与临时文件留在 `build/model-ui-20261029`。正式更新只替换经过验证的发行文件，保留用户数据。
