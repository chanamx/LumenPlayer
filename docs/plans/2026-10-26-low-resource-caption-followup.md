# 当前低配机器的字幕模型补充验证

用户约束：Index-Translate、Hy-MT2 等 1.8–2B 模型保留为中配以上可选档；继续寻找当前 i5-7200U / 8GB 机器能维持字幕实时性的较轻模型。优先 2026 新训练或实质蒸馏，不把旧权重量化或维护日期当新模型。

1. 使用 Web Composite Search 与 Sn Search Code 做外部发现，读取作者模型卡与训练记录；保存出生日期、能力、体积和获取渠道。
2. 优先验证 TranslatePsy-EuroNano 的 CPU 路径（仅欧语与英语），补查中文、日语轻型模型；法语识别候选严格区分新架构与旧架构的新微调。
3. 通过运行兼容性与资源筛选后，逐个运行模型；沿用提交余量保护，不并行推理，不改全局依赖和播放器设置。
4. 使用保留的文本和音频夹具核对翻译方向、数字、否定、延迟与内存；组件结果不替代播放器联合实测。
5. 写入独立报告和硬件分档候选表，保留前轮证据不变；验证正式发布关键文件未变和本轮辅助进程退出。

本轮不切换正式安装包、不集成生产模型，也不凭搜索结果承诺实时性。
