# LumenPlayer 2.0.0 窗口白边修复验证 — 2026-10-24

已修复自绘主窗口与系统默认边框绘制混用的问题，正式目录已替换，安装包已重建。生产修改仅在 src/main.cpp 的 MainProc 非客户区消息处理块，其他 23 个生产文件、34 个 DLL、模型和字幕 CPU 配置均保持内容一致。

原版自有窗口初始外框为 1120×700，客户区为 1104×684，四周偏移 8 像素；失活及系统边框重画时，两侧 12 个采样点中有 8 个浅色点，激活时有 2 个。修复后客户区填满窗口，采样点均无浅色边框，像素读取均有效。两侧采样使用应用自身窗口 DC 的中线边缘点，不是全桌面截图，也不是对所有视频画面像素判白。

修复统一初次创建和后续尺寸重算，激活变化保留默认窗口状态处理并禁止默认边框重绘，非最小化时由自绘层负责边框。最小化状态仍交给默认处理。依据为微软的 [WM_NCACTIVATE](https://learn.microsoft.com/en-us/windows/win32/winmsg/wm-ncactivate) 和 [自绘窗口边框说明](https://learn.microsoft.com/en-us/windows/win32/dwm/customframe)。

本轮通过的验证：

- 133 项边框专项：首次创建、失活/激活、原生模态窗口取消与恢复、系统边框和主题重绘、100/125/150/200% 界面比例、两种尺寸、列表开关及视频视口对齐、最大化、最小化/恢复、全屏往返、两种播放路径和软硬解偏好切换、暂停保持与继续播放。界面比例由测试设置；未进行真实跨显示器 DPI 切换。
- 175 项播放控件回归、637 项列表布局回归。
- 1840 项渲染及 433 项兼容解码回归，合计 2273 项。
- 136 项现代核心回归，包含轨道、解码、HDR 与真实实时字幕模型输入、结果和关闭清理。

真实鼠标操作系统文件选择框尚未验收：Computer Use 启动申请返回授权超时；另外一个原生 IFileDialog 自动取消试验未正常退出，原因未确认，该试验不作为成功证据。已完成的是应用自身窗口消息、普通原生模态窗口和播放状态的程序内回归，不将其称为完整鼠标选文件实测。当前正式 EXE 未另做 GUI 启动实测，确认了其构建、文件身份、完整运行文件和安装包载荷；同一生产源码的原生回归均通过。

前期保留了边缘采样窗口超出显示工作区导致不可读点的测试失败，以及旧控件回归移动到深层目录后找不到相对媒体路径的失败。修正测试工作区/运行层级后重新执行，产品未因此增加延迟或更改列表逻辑。原始失败日志保留在本轮目录，不计入通过项。
