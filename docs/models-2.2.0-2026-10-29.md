# Lumen Player 2.2.0：日中翻译与模型下载源

本轮将 NanoSakura 0.3B INT8 接入实际模型列表与播放器翻译队列，并扩充现有模型的固定下载入口。中文识别默认仍为 Zipformer，七个既有模型的文件名、大小和 SHA-256 均保持一致。下载不会自动切换模型；发行程序与安装包均不包含模型权重。

## 使用与资源

在设置的“模型与语言”中安装“日语 · Moonshine Tiny”，将其用作识别；安装“日语 → 中文 · NanoSakura INT8”，目标选择中文，再点“用作翻译”。按 C 开启实时字幕。模型可在同一窗口删除，删除会先释放使用中的模型。NanoSakura 只支持日语文本译为简体中文，界面和后台都会拒绝其他语言方向。

NanoSakura 固定版本为 `telecomadm1145/NanoSakura-0.3B-Onnx@a46f2ed2dd1b8a601f0d8f5cb381804e745fae72`，作者模型卡声明 MIT。五个文件共 **296,214,213 字节，282.49 MiB**。日语识别包另需约 30.82 MiB，两者合计约 313.31 MiB。原生推理复用播放器既有的 ONNX Runtime 1.28.2，CPU 单线程，无需额外安装 Python、.NET 或 llama 运行包。模型加载和整句翻译期间继续显示识别原文。

当前 i5-7200U / 8 GiB Windows 机器的最终 UCRT 构建实测如下。单句数据来自 20 条诊断文本；连续播放数据来自同一条约两分钟音轨，不能按独立片源数量解释。

| 测量 | 结果与口径 |
| --- | --- |
| 20 句原生文本翻译 | 中位数约 1.39 秒，P95 约 2.17 秒；分词器和模型冷加载约 8.03 秒 |
| 单独原生翻译进程峰值工作集 | 约 612.0 MiB，包含进程与模型开销 |
| 日语连续播放、识别、翻译 | 约 120.38 秒，25 条识别结果、25 条译文、25 条双语导出，1,860,531 帧 PCM |
| 连续播放译文出现延迟 | 相对识别片段结束位置，中位数约 1.19 秒，P95 约 2.23 秒，最大约 2.87 秒；包含识别断句及翻译等待，未计媒体开始前模型准备 |
| 连续联合运行内存 | 结束前私有提交约 503.8 MiB，进程峰值工作集约 721.7 MiB |
| 连续联合运行 CPU | 累积约 97.17 CPU 秒 / 120.38 秒墙钟时间；该值是进程 CPU 时间，未计系统其他进程 |
| 停止和时间线 | 连续播放停止约 77.8 毫秒；独立翻译中断约 155.8 毫秒；旧 generation 不进入显示或导出 |

20 句最终原生输出与前轮参考实现逐字一致，705 组分词与解码对照通过。这验证移植的一致性。语言质量仍受模型与识别结果限制：清晰样本生成“田中先生的太太是大学老师”；另一个样本中日语识别有明显错词，译文出现“施展香甜”等不自然表达。前轮文本诊断中，兄妹接送关系也有误译。该包适合作为轻量日译中选项，需结合原文或双语字幕判断具体内容。

原生字幕画面：[日语音频译为中文](../build/nanosakura-integration-20261029/playback-final-ja-01/japanese-chinese-captions.png)。它来自实际播放/识别/翻译后的原生绘制表面，完整桌面鼠标操作另属验收范围。

## 下载入口

| 模型 | 当前可选渠道 | 文件范围 |
| --- | --- | --- |
| Zipformer 中文 CTC | 魔搭、HF 社区镜像、HF 原站、GitHub 发布、GitHub API | 魔搭提供主体，词表使用已核验 HF/镜像；GitHub 两入口提供完整压缩包 |
| Moonshine 日语 Tiny | Moonshine 官方 CDN | 现有八个 ORT 配套文件；暂未找到完整相同的第二套来源 |
| Moonshine 英语 Tiny | Moonshine 官方 CDN、官方 HF 归档、HF 社区镜像 | 八个文件均有替代入口 |
| Moonshine 英语 Small | Moonshine 官方 CDN、官方 HF 归档、HF 社区镜像 | 八个文件均有替代入口 |
| Moonshine 德语 Tiny | Moonshine 官方 CDN | 现有八个 ORT 配套文件；暂未找到完整相同的第二套来源 |
| Hy-MT2 Q4 | 魔搭、HF 社区镜像、HF 原站 | 权重固定；运行包自动使用 GitHub 发布或 API 备用入口 |
| Index-Translate Q4 | 魔搭、HF 社区镜像、HF 原站 | 权重固定；运行包自动使用 GitHub 发布或 API 备用入口 |
| NanoSakura 日中 INT8 | 作者 HF、HF 社区镜像 | 五个文件均有两套入口 |

HF 镜像在界面中明确标为社区镜像。魔搭的 `.cn` 与 `www.modelscope.cn` 是同平台的两个入口，GitHub 发布页与 API 也是同平台的备用路径；文件 URL 数量不等于独立镜像站数量。日语、德语检索到的部分 HF 同名模型是 safetensors 等其他格式，未作为现有 ORT 文件的下载源混入。

每个入口绑定文件大小、SHA-256 和固定上游版本。探测记录有 92 个候选条目：90 个通过；一个公共网关返回 403，另一个同站条目按冷却规则跳过，两者未加入列表。大文件的普遍探测核对了范围响应、长度和已知本地前 64 KiB；完整下载后仍必须核对整文件 SHA-256。不能将范围探测称作全部大文件的整包重下。

最终 UCRT 原生下载器已完成 NanoSakura 镜像整包、英语官方 HF 整包、日语官方 CDN 整包和 llama GitHub API 运行包的下载、全量校验、安装与删除。中文 GitHub API 完整压缩包也完成全量校验、安装与删除；最终成功一次复用了先前已完整下载并通过 SHA-256 的压缩包，约 21.75 秒是解码、展开及校验耗时，不能作为网络下载速度。作者 HF 的 NanoSakura 整包亦在前序原生构建中完成交叉核验。精确文件 URL 与身份在 [caption-models.json](../resources/caption-models.json)，源补充记录在 [caption-source-supplement.json](../resources/caption-source-supplement.json)，网络探测在 [source-probes.json](../build/nanosakura-integration-20261029/research/source-probes.json)。

自动模式按已核验顺序尝试来源，断流后可从下一入口续传同一文件。收到 403/429/503 后，本次安装不再请求该站点，继续尝试独立来源；手动选定来源时主体保持该选择，辅助文件与运行包的例外会显示说明。保留 Windows 系统代理支持与 TLS 校验。完整性不符或缺少配套文件不会激活为已安装模型；遇到超长响应会中断读取，重试时仍校验完整文件，已接收的正确前缀可以继续使用。

中文压缩包实测发现，本机系统 tar 调用外部 bzip2 解码时停滞。现改为复用已经随程序发布的 UCRT bzip2 库，先按 64 KiB 缓冲流式解码，再由系统 tar 展开；限制解码总量与时间，支持取消，激活前清理临时 tar。没有增加运行库文件或外部安装要求。

初次构建误用了 GCC/MSVCRT，原有 `playlistwidth=nan` 边界回归发现了差异；所有最终产物已用上一版记录的 LLVM-MinGW UCRT 重建并重测。构建脚本现记录编译器身份，检查自身 EXE/DLL 的导入表并拒绝 MSVCRT。没有为掩盖该工具链问题修改配置解析逻辑。另保留一次监护超时过短以及渲染媒体未复制完整的测试准备失败现场；补齐条件后的最终回归记录单独绑定。

完整桌面鼠标流程、系统注册项/快捷方式、跨物理显示器 DPI、实体 HDR/功放和长时间高负载矩阵仍需对应环境验收。此次字体/窗口检查、GPU 读取、模型内存以及短期连续播放结论均以以上实测范围为准。

## 交付与复核

正式程序为 [dist/LumenPlayer.exe](../dist/LumenPlayer.exe)，SHA-256 为 `f4f2cccd2cd8a9d7ed2c3947bca77dbdb5618b9ac067ee5fa8045611afd95911`。111 个运行文件逻辑大小共 214,918,897 字节；其中没有语音或翻译权重。程序 EXE 已恢复 XPRESS8K 透明压缩，压缩前后内容哈希一致。

最终安装包为 [LumenPlayer-2.2.0-x64-setup.exe](../build/nanosakura-integration-20261029/installer/LumenPlayer-2.2.0-x64-setup.exe)，68,308,547 字节，约 65.14 MiB；SHA-256 为 `6f99c91c3a6ec30d29c32eb7e752a7e3fd3e3550dbb9f6e34aa413f15c7dcb65`。安装包排除设置、列表、缓存及新旧模型目录。用户仍可在模型窗口自行安装、切换或删除模型，下载完成不自动改变当前识别与翻译选择。

本轮完整证据绑定见 [validation.json](../build/nanosakura-integration-20261029/validation.json)，运行 `python test/finalize_nanosakura_release.py --check-only` 核对冻结的源码、模型目录、测试结果、运行文件与安装包身份。旧版源码、旧 EXE 和发布清单保存在 [2.1.2-source-recovery.zip](../build/nanosakura-integration-20261029/before/2.1.2-source-recovery.zip)，没有覆盖旧的实测失败现场与恢复材料。
